X650 Holybro Quadrotor: Indoor Autonomous Flight Platform

Ongoing Project

X650 Holybro quadrotor during indoor flight testing using OptiTrack motion capture, Raspberry Pi 5, ROS 2 Jazzy, Pixhawk 6X, and PX4 Offboard Control.

Description:

This project focuses on the development and integration of a GPS-denied indoor flight platform based on the Holybro X650 quadcopter, Pixhawk 6X, and Raspberry Pi 5. The platform is being prepared for advanced control, perception, and AI-based experiments using an OptiTrack motion capture system.

The system integrates PX4 Autopilot, ROS 2 Jazzy, Micro XRCE-DDS, and VRPN to enable real-time motion-capture-based state estimation and offboard control.

System Development

  1. Quadrotor Assembly: Assembled and configured the Holybro X650 frame, motors, ESCs, power system, and Pixhawk 6X flight controller.
  2. ESC and Thrust Configuration: Configured and calibrated the ESCs and propulsion system to resolve the initial insufficient-thrust problem and achieve reliable takeoff performance.
  3. Companion Computer Integration: Integrated a Raspberry Pi 5 running Ubuntu 24.04 with the Pixhawk 6X through a physical serial connection.
  4. OptiTrack Motion Capture Integration: Integrated OptiTrack Motive with ROS 2 Jazzy using VRPN and Micro XRCE-DDS to stream real-time position and orientation measurements to the PX4 flight controller.
  5. GPS-Denied State Estimation: Configured PX4 EKF to fuse external vision/motion-capture measurements for indoor position and attitude estimation.
  6. Flight Controller Tuning: Tuned the flight-control parameters and PID controllers to achieve stable hovering and reliable indoor flight.
  7. PX4 Offboard Control: Implemented and tested Offboard Control Mode, allowing external commands and trajectories to be generated through ROS 2.
  8. AI Vision-Based Control: Preparing the platform for the integration of AI-based visual perception and autonomous control.

System Architecture

OptiTrack Motive → VRPN → ROS 2 Jazzy → Raspberry Pi 5 → Micro XRCE-DDS → Pixhawk 6X → PX4 → X650 Quadrotor
